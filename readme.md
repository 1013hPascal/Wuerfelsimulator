\# Würfelapp mit frei definierbaren Seiten



Diese App erstellt einen Würfel mit beliebig vielen Seiten und frei wählbarer Beschriftung.  

Die Beschriftungen werden aus einer CSV Datei geladen. Beim Würfeln wird das Ergebnis per Sprachausgabe vorgelesen.



So können auch blinde Menschen Würfel nutzen, die mehr als 6 Seiten haben oder spezielle Texte statt Zahlen verwenden.  

Das erleichtert die Teilnahme an Spielen mit besonderen Würfeln.



\## Funktionen



\- Beliebig viele Würfelseiten möglich

\- Jede Seite kann einen eigenen Text haben

\- Würfelergebnis wird per Sprachausgabe vorgelesen

\- Einfache Pflege über eine CSV Datei



\## Datei `dice.csv`



In die Datei `dice.csv` kommt pro Zeile genau eine Würfelseite.  

Der Text der Zeile ist der Text, der auf der Würfelseite steht.
